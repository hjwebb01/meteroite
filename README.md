# Meteroite

Meteroite is a browser workspace for building web projects with AI. Describe what you want to create, edit the code, and preview your app in one place. You can also bring in an existing GitHub repository or export your project to a new one.

## Create your first project

1. Open Meteroite and sign in.
2. Choose **New Project** and describe what you want to build. For example: “Create a recipe app with a search bar and a favorites list.”
3. Use the conversation sidebar to request changes or ask questions about your project.
4. Open **Code** to browse files and edit them directly.
5. Switch to **Preview** to see your app running.

## Work with an existing project

Choose **Import Project** on the project screen and enter your GitHub repository URL. Connect your GitHub account through your account settings if prompted.

You can return to your projects from the project list and revisit previous conversations from the conversation sidebar.

## Preview your app

The **Preview** tab installs your project's dependencies and starts its development server. The terminal panel shows installation and startup output.

If your project needs different commands, open **Preview Settings** and set the **Install Command** and **Start Command**. Save your changes to restart the preview with those settings. You can also use the restart button to start it again.

## Export to GitHub

Open your project and choose **Export**. Enter a repository name, select public or private visibility, and optionally add a description. Choose **Create Repository**, then use **View on GitHub** when the export finishes.

Importing and exporting require a connected GitHub account.
